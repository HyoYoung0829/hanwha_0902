# 0908 학습 정리

오늘 예제는 FastAPI로 API를 만들 때 자주 쓰는 기본 문법들을 순서대로 익히는 내용이다.

크게 보면 다음 흐름으로 이어진다.

1. FastAPI 앱 만들기
2. 경로 매개변수 받기
3. 쿼리 매개변수 받기

## 1. FastAPI 기본 구조

FastAPI는 먼저 `FastAPI`를 import하고, 앱 인스턴스를 만든 뒤 데코레이터로 API 주소를 연결한다.

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
async def root():
    return {"message": "Hello World"}
```

`@app.get("/")`는 `/` 주소로 GET 요청이 들어왔을 때 아래 함수를 실행하겠다는 뜻이다.

`async def`는 비동기 함수다. FastAPI 예제에서는 기본적으로 자주 사용한다.

## 2. 경로 매개변수

URL 경로 안에 값을 넣어서 받을 수 있다.

```python
@app.get("/items/{item_id}")
async def read_item(item_id: int):
    return {"item_id": item_id}
```

`/items/123`으로 요청하면 `item_id`에 `123`이 들어온다.

타입을 `int`로 지정하면 FastAPI가 자동으로 변환하고 검사한다. 숫자로 바꿀 수 없는 값이 들어오면 함수가 실행되지 않고 `422` 에러가 난다.

## 3. API 선언 순서

FastAPI는 위에서 아래로 경로를 확인한다.

그래서 고정 경로는 동적 경로보다 먼저 선언하는 것이 좋다.

```python
@app.get("/users/me")
async def read_user_me():
    return {"user_id": "the current user"}

@app.get("/users/{user_id}")
async def read_user(user_id: str):
    return {"user_id": user_id}
```

만약 `/users/{user_id}`를 먼저 선언하면 `/users/me`의 `me`가 `user_id`로 처리될 수 있다.

## 4. 쿼리 매개변수

쿼리 매개변수는 URL에서 `?` 뒤에 붙는 값이다.

예시:

```text
http://127.0.0.1:8000/items/?skip=0&limit=10
```

FastAPI에서는 함수 인자로 기본값을 주면 쿼리 매개변수로 처리된다.

```python
@app.get("/items/")
async def read_item(skip: int = 0, limit: int = 10):
    return fake_items_db[skip : skip + limit]
```

`skip`은 몇 개를 건너뛸지, `limit`은 몇 개를 가져올지 정하는 값으로 생각하면 된다.

## 5. Boolean 쿼리

쿼리 매개변수에 `bool` 타입도 사용할 수 있다.

```python
@app.get("/items/{item_id}")
async def read_item(item_id: str, q: str | None = None, short: bool = False):
    ...
```

FastAPI는 아래 값들을 알아서 `True`로 이해한다.

- `true`
- `True`
- `1`
- `yes`
- `on`

아래 값들은 `False`로 이해한다.

- `false`
- `0`
- `no`
- `off`

## 6. 경로에 `/`까지 포함해서 받기

보통 경로 매개변수는 `/`를 포함하지 못한다.

파일 경로처럼 `/`까지 포함해서 받고 싶으면 `:path`를 붙인다.

```python
@app.get("/files/{file_path:path}")
async def read_file(file_path: str):
    return {"file_path": file_path}
```

## 7. 요청 Body와 Pydantic

POST나 PUT처럼 body 데이터를 받을 때는 보통 Pydantic 모델을 함께 사용한다.

```python
from pydantic import BaseModel

class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None
```

이렇게 모델을 만들면 요청 body가 이 구조에 맞는지 자동으로 검사된다.

```python
@app.post("/items/")
async def create_item(item: Item):
    return item
```

`Item` 모델은 "이 데이터는 이런 모양이어야 한다"는 약속이라고 보면 된다.

## 8. 모델 데이터를 수정해서 응답하기

Pydantic 모델 자체를 바로 수정하기보다는 `model_dump()`로 dict로 바꾼 뒤 값을 추가하는 방식이 자주 쓰인다.

```python
item_dict = item.model_dump()
item_dict.update({"price_with_tax": price_with_tax})
```

모델은 검증용 구조로 두고, 응답용 데이터는 dict로 만들어 다루는 느낌이다.

## 9. Path, Query, Body 함께 받기

FastAPI는 경로 매개변수, 쿼리 매개변수, body를 한 함수에서 같이 받을 수 있다.

```python
@app.put("/items/{item_id}")
async def update_item(item_id: int, q: str | None = None, item: Item = None):
    return {"item_id": item_id, "q": q, "item": item}
```

대략 이렇게 구분된다.

- `item_id`: URL 경로에서 받음
- `q`: 쿼리에서 받음
- `item`: 요청 body에서 받음

## 10. 여러 Body 모델 받기

body 안에 여러 객체가 들어올 수도 있다.

예를 들어 상품 정보와 사용자 정보를 동시에 받는 경우다.

```python
class Item(BaseModel):
    name: str
    price: float

class User(BaseModel):
    username: str
    full_name: str | None = None
```

```python
@app.put("/items/{item_id}")
async def update_item(item_id: int, item: Item, user: User):
    return {"item_id": item_id, "item": item, "user": user}
```

이 경우 FastAPI는 body 안에서 `item`, `user`를 각각 찾아서 각 모델로 검사한다.

## 11. Body와 Field

`Body()`는 FastAPI에서 요청 body를 어떻게 받을지 정할 때 쓴다.

`Field()`는 Pydantic 모델 안의 각 필드를 더 자세히 검증할 때 쓴다.

```python
from pydantic import Field

class Item(BaseModel):
    name: str
    description: str | None = Field(default=None, max_length=300)
    price: float = Field(gt=0)
```

정리하면:

- `Body()`: API 함수의 파라미터 쪽 설정
- `Field()`: 모델 클래스 내부의 필드 설정

## 12. 중첩 모델

객체 안에 또 다른 객체가 들어오는 경우, 모델 안에 다른 모델을 넣을 수 있다.

```python
class Image(BaseModel):
    url: HttpUrl
    name: str

class Item(BaseModel):
    name: str
    price: float
    image: Image | None = None
```

이렇게 하면 `image`에는 아무 dict나 들어오는 것이 아니라 `Image` 구조에 맞는 데이터만 들어올 수 있다.

`HttpUrl`을 사용하면 단순 문자열이 아니라 실제 HTTP/HTTPS URL 형태인지도 검사할 수 있다.

## 13. 리스트 Body

body 자체가 리스트일 수도 있다.

```python
@app.post("/images/multiple/")
async def create_multiple_images(images: list[Image]):
    return images
```

이 경우 요청 body는 `Image` 객체들이 들어있는 리스트 형태가 된다.

## 14. 응답 모델

응답 모델은 서버가 클라이언트에게 어떤 형태의 JSON을 돌려줄지 정하는 것이다.

함수의 반환 타입으로 지정할 수 있다.

```python
@app.post("/items/")
async def create_item(item: Item) -> Item:
    return item
```

또는 `response_model`을 사용할 수도 있다.

```python
@app.get("/items/", response_model=list[Item])
async def read_items():
    return [
        {"name": "Portal Gun", "price": 42.0},
        {"name": "Plumbus", "price": 32.0},
    ]
```

둘 다 사용할 수 있지만, 실제 반환값과 API 응답 모양을 분리하고 싶을 때는 `response_model`이 유용하다.

## 15. 응답에서 기본값 제외하기

`response_model_exclude_unset=True`를 사용하면 설정되지 않은 기본값은 응답에서 제외할 수 있다.

```python
@app.get("/items/{item_id}", response_model=Item, response_model_exclude_unset=True)
async def read_item(item_id: str):
    return items[item_id]
```

응답 모양을 조정할 수 있지만, 복잡해지면 별도의 응답 모델을 만드는 편이 더 깔끔하다.

## 16. 상태 코드

응답 상태 코드를 직접 지정할 수 있다.

```python
@app.post("/items/", status_code=201)
async def create_item(name: str):
    return {"name": name}
```

자주 쓰는 상태 코드 의미는 다음 정도만 기억하면 된다.

| 범위 | 의미 |
| --- | --- |
| `2xx` | 성공 |
| `3xx` | 리다이렉션 |
| `4xx` | 클라이언트 오류 |
| `5xx` | 서버 오류 |

코드 숫자를 직접 적을 수도 있지만, FastAPI의 `status.HTTP_201_CREATED` 같은 상수를 쓰면 의미가 더 잘 보인다.

## 17. HTTPException

클라이언트에게 에러 응답을 보내고 싶을 때는 `HTTPException`을 사용한다.

```python
from fastapi import HTTPException

@app.get("/items/{item_id}")
async def read_item(item_id: str):
    if item_id not in items:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"item": items[item_id]}
```

`HTTPException`은 일반적인 반환값이 아니라 예외다.

그래서 `return`이 아니라 `raise`로 사용한다. 실행 중간에서 요청 처리를 바로 멈추고 에러 응답을 보낼 수 있다.

## 오늘의 핵심 요약

- FastAPI는 데코레이터로 URL과 함수를 연결한다.
- 경로 매개변수는 `/items/{item_id}`처럼 받는다.
- 쿼리 매개변수는 함수 인자의 기본값으로 받는 경우가 많다.
- 타입 힌트를 쓰면 FastAPI가 자동으로 변환과 검증을 해준다.
- 요청 body는 Pydantic 모델로 구조를 잡고 검사한다.
- `Body()`는 API 함수 쪽, `Field()`는 Pydantic 모델 필드 쪽 설정이다.
- 모델 안에 모델을 넣으면 중첩 JSON 구조도 검증할 수 있다.
- 응답 모델을 지정하면 API가 밖으로 내보내는 데이터 형태를 제한할 수 있다.
- 상태 코드는 요청 결과를 클라이언트에게 알려주는 약속이다.
- 에러 응답은 `HTTPException`을 `raise`해서 보낸다.
