# 0904 학습 정리

오늘은 클래스 복습과 NumPy 배열 다루기가 중심이었다.

## 1. 클래스와 메서드

클래스를 사용하면 데이터와 동작을 하나로 묶을 수 있다.

```python
class TextService:
    def __init__(self, max_length: int = 100) -> None:
        self.max_length = max_length

    def summarize(self, text: str) -> str:
        cleaned = text.strip()
        if not cleaned:
            raise ValueError("본문을 입력하세요.")
        return cleaned[: self.max_length]
```

이 예제의 흐름은 다음과 같다.

1. `TextService` 객체를 만든다.
2. `max_length`를 객체 안에 저장한다.
3. `summarize()`가 문자열 앞뒤 공백을 제거한다.
4. 빈 문자열이면 에러를 낸다.
5. 정상이면 최대 길이만큼 잘라서 반환한다.

```python
service = TextService(max_length=20)
print(service.summarize("클래스는 데이터와 동작을 함께 관리합니다."))
```

## 2. NumPy 배열 만들기

NumPy는 숫자 데이터를 배열로 다룰 때 많이 사용한다.

```python
import numpy as np

arr = np.array([[1, 2, 3], [4, 5, 6]])
```

리스트와 비슷해 보이지만, NumPy 배열은 숫자 계산에 훨씬 편하다.

## 3. 브로드캐스팅

배열 전체에 한 번에 연산을 적용할 수 있다.

```python
arr + 10
arr * 2
```

각 요소를 하나씩 반복문으로 꺼내지 않아도 전체 값에 계산이 적용된다.

## 4. 통계 계산

NumPy 배열은 합계, 평균, 최댓값 같은 계산을 바로 할 수 있다.

```python
arr.sum()
arr.mean(axis=0)
arr.max(axis=1)
```

`axis`는 계산 방향을 정한다.

| 표현 | 의미 |
| --- | --- |
| `axis=0` | 열 방향으로 계산 |
| `axis=1` | 행 방향으로 계산 |

## 5. 인덱싱과 슬라이싱

배열에서 원하는 위치의 값을 꺼낼 수 있다.

```python
arr[1, -1]
```

2차원 배열에서는 `[행, 열]` 순서로 접근한다.

슬라이싱도 가능하다.

```python
arr1[1:5]
arr2[4:]
arr3[-3:-1]
arr4[::2]
```

기본 규칙은 `start:end:step`이다.

- `start`: 시작 위치
- `end`: 끝 위치, 포함하지 않음
- `step`: 몇 칸씩 이동할지

## 6. 2차원 슬라이싱

2차원 배열에서는 행과 열을 함께 잘라낼 수 있다.

```python
matrix[1:, 1:]
```

이 코드는 1번 행부터 끝까지, 1번 열부터 끝까지 가져온다.

## 7. Boolean Indexing

조건에 맞는 값만 골라낼 수도 있다.

```python
mask = matrix > 5
matrix[mask]
```

`matrix > 5`는 각 요소가 5보다 큰지 `True`, `False`로 표시한 마스크를 만든다.

그 마스크를 배열에 넣으면 조건에 맞는 값만 추출된다.

## 8. reshape와 전치

`reshape()`는 배열의 모양을 바꾼다.

```python
vec = np.arange(12)
matrix_3x4 = vec.reshape(3, 4)
```

`np.arange(12)`는 0부터 11까지의 숫자를 만든다.

`reshape(3, 4)`는 그 숫자들을 3행 4열 배열로 바꾼다.

전치는 행과 열을 바꾸는 것이다.

```python
transposed = matrix_3x4.T
```

3행 4열 배열은 전치하면 4행 3열이 된다.

## 오늘의 핵심 요약

- 클래스는 상태와 동작을 함께 묶을 수 있다.
- NumPy 배열은 숫자 계산을 편하게 해준다.
- 배열 전체에 `+`, `*` 같은 연산을 바로 적용할 수 있다.
- `axis=0`, `axis=1`로 계산 방향을 정할 수 있다.
- 2차원 배열은 `[행, 열]` 방식으로 접근한다.
- 슬라이싱은 `start:end:step` 구조다.
- Boolean Indexing은 조건에 맞는 값만 뽑을 때 쓴다.
- `reshape()`는 배열 모양 변경, `.T`는 전치다.
