## 1. 문자열 기본 조작

문자열은 길이를 확인하거나, 포함 여부를 검사하거나, 일부만 잘라낼 수 있다.

```python
text = "Hello, World!"

len(text)
"free" in text
text[2:5]
```

자주 나온 문자열 메서드는 다음과 같다.

| 메서드 | 의미 |
| --- | --- |
| `upper()` | 대문자로 변환 |
| `lower()` | 소문자로 변환 |
| `strip()` | 앞뒤 공백 제거 |
| `replace()` | 특정 문자열 바꾸기 |
| `split()` | 문자열 나누기 |

## 2. 질문 정리 함수

입력받은 질문을 정리하는 함수를 만들었다.

```python
def normalize_question(question: str, max_length: int = 100) -> str:
    cleaned = question.strip()
    if not cleaned:
        raise ValueError("질문을 입력하세요.")
    return cleaned[:max_length]
```

흐름은 간단하다.

1. 앞뒤 공백을 제거한다.
2. 비어 있으면 에러를 발생시킨다.
3. 너무 긴 질문은 최대 길이만큼 자른다.

## 3. 예외 처리

에러가 날 수 있는 코드는 `try`, `except`로 감쌀 수 있다.

```python
try:
    result = normalize_question("  Python이란?  ")
    print(result)
except ValueError as error:
    print("입력 오류:", error)
```

`raise ValueError(...)`는 일부러 에러를 발생시키는 코드다.

`except ValueError`는 그 에러가 발생했을 때 어떻게 처리할지 정하는 부분이다.

## 4. 리스트를 돌면서 결과 만들기

여러 질문을 받아서 각각의 상태를 만든 예제도 있었다.

```python
def build_responses(questions: list[str]) -> list[dict[str, str]]:
    responses = []
    for index, question in enumerate(questions, start=1):
        try:
            cleaned = normalize_question(question)
            responses.append({"id": str(index), "question": cleaned, "status": "ready"})
        except ValueError:
            responses.append({"id": str(index), "question": "", "status": "invalid"})
    return responses
```

여기서 기억할 부분은 `enumerate()`다.

리스트를 돌면서 값뿐만 아니라 번호까지 같이 가져올 수 있다.

```python
for index, question in enumerate(questions, start=1):
```

## 5. 클래스

클래스는 데이터와 동작을 함께 묶는 방법이다.

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def greet(self):
        print("Hello, my name is " + self.name)

    def display_info(self):
        print(f"이름: {self.name}, 나이: {self.age}")
```

`__init__`은 객체가 만들어질 때 처음 실행되는 초기화 함수다.

`self.name`, `self.age`처럼 객체가 자기 데이터를 가지고 있게 만들 수 있다.

```python
p1 = Person("홍길동", 16)
```

이렇게 만든 `p1` 같은 값을 객체라고 부른다.

## 6. Matplotlib 그래프

NumPy 배열을 만들고 Matplotlib으로 선 그래프를 그렸다.

```python
import matplotlib.pyplot as plt
import numpy as np

ypoints = np.array([3, 8, 1, 10, 24])
plt.plot(ypoints, "o:r")
plt.show()
```

`"o:r"`의 의미는 다음과 같다.

- `o`: 각 데이터 위치를 원으로 표시
- `:`: 점선으로 연결
- `r`: 빨간색으로 표시
