# 0902 학습 정리

오늘은 Python 기본 문법을 가볍게 훑은 날이다.

자료형, 리스트, 딕셔너리, 조건문, 반복문, 함수까지 이어지면서 "데이터를 만들고, 검사하고, 필요한 형태로 처리하는 흐름"을 연습했다.

## 1. 기본 자료형

Python에서는 값의 종류에 따라 타입이 나뉜다.

```python
service_name: str = "summary-api"
max_length: int = 100
temperature: float = 0.2
is_enabled: bool = True
```

자주 쓰는 타입은 이 정도다.

| 타입 | 의미 | 예시 |
| --- | --- | --- |
| `str` | 문자열 | `"summary-api"` |
| `int` | 정수 | `100` |
| `float` | 실수 | `0.2` |
| `bool` | 참/거짓 | `True`, `False` |

`type()`을 사용하면 값의 타입을 확인할 수 있다.

```python
print(type(service_name), type(max_length))
```

## 2. 리스트

리스트는 여러 값을 순서대로 담는 자료형이다.

```python
requests = ["첫 번째 질문", "두 번째 질문"]
```

질문 목록, 사용자 목록, 결과 목록처럼 여러 개를 모아서 다룰 때 사용한다.

리스트의 개수는 `len()`으로 확인할 수 있다.

```python
len(requests)
```

## 3. 딕셔너리

딕셔너리는 키와 값을 묶어서 저장하는 자료형이다.

```python
response = {
    "status": "success",
    "count": len(requests),
    "items": requests,
}
```

API 응답처럼 구조가 있는 데이터를 표현할 때 자주 쓴다.

값을 꺼낼 때는 키를 사용한다.

```python
response["count"]
```

## 4. 반복문과 조건문

리스트를 하나씩 돌면서 필요한 값만 골라낼 수 있다.

```python
questions = ["asyncio란?", "", "FastAPI란?"]
valid_questions: list[str] = []

for question in questions:
    cleaned = question.strip()
    if not cleaned:
        continue

    valid_questions.append(cleaned)
```

여기서 핵심은 다음과 같다.

- `strip()`: 문자열 앞뒤 공백 제거
- `if not cleaned`: 빈 문자열인지 확인
- `continue`: 이번 반복은 건너뛰기
- `append()`: 리스트에 값 추가

결과적으로 빈 질문은 제외하고 실제 질문만 남긴다.

## 5. 함수

반복해서 쓸 코드는 함수로 만들 수 있다.

```python
def sum(a, b):
    return a + b
```

예제에서는 사칙연산 함수를 만들었다.

```python
def sum(a, b):
    return a + b

def sub(a, b):
    return a - b

def div(a, b):
    return a / b

def mul(a, b):
    return a * b
```

함수는 값을 받아서 처리한 뒤 `return`으로 결과를 돌려준다.

## 6. 오늘 나온 개념

`asyncio`는 Python에서 비동기 처리를 할 때 사용하는 라이브러리다.

`FastAPI`는 Python으로 API 서버를 빠르게 만들 수 있는 웹 프레임워크다. JavaScript의 Express.js와 비슷한 역할로 생각하면 된다.

## 오늘의 핵심 요약

- 변수에는 문자열, 숫자, 참/거짓 같은 값을 담을 수 있다.
- 리스트는 여러 값을 순서대로 담는다.
- 딕셔너리는 키와 값으로 구조화된 데이터를 담는다.
- `strip()`으로 공백을 제거할 수 있다.
- `if`, `continue`를 사용하면 조건에 따라 흐름을 제어할 수 있다.
- 함수는 자주 쓰는 로직을 이름 붙여 재사용하는 방법이다.
